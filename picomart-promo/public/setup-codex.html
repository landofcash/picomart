Set up Picomart for Codex

Picomart AI-assisted ordering prepares PathUSD orders on Tempo. Install the MCP server from project source and connect it to your configured quote service, Sync API, and buyer app.

The integration prepares encrypted order details and tracks payment confirmation. Buyers review the order and approve payment using their built-in Picomart wallet. The integration does not sign payments.

Local development setup

With Node.js 22 or later, install and build the picomart-mcp directory from project source. Register a stdio server in your MCP client using node and the absolute path to its dist/server.js file. Configure matching quote-service, Sync, and buyer HTTPS origins in the client. Set PICOMART_QUOTE_PUBLIC_KEYS to a JSON object mapping each quote signing key ID to its public base64url Ed25519 key.

Configure PICOMART_X402_ORIGIN, PICOMART_SYNC_ORIGIN, and PICOMART_FRONTEND_ORIGIN for the services you use. HTTPS origins are required for hosting; HTTP localhost origins are supported for development. Install the same public quote keyring in the buyer app. Keep wallet keys and private quote-signing keys out of MCP client configuration.
